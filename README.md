# Caltech Mathathon 2026 — Working Repository

This is a working repository for our preparation for the Caltech Mathathon.

**Team**

## Purpose

This repository is currently a private research notebook.

The aim is not to prepare a large research proposal.

Instead, we want to identify concrete mathematical directions of the form

$$
\text{theme}
\longrightarrow
\text{specific problem}
\longrightarrow
\text{plan of attack}
\longrightarrow
\text{role of AI}.
$$

## Current directions

1. Colin's existing AI-assisted mathematical work.
2. Colin's open research questions.
3. Ravi's research directions.
4. Possible crossover problems.
5. Experiments with AI-assisted proof discovery.
6. Small Lean/formal-verification experiments.
7. Material that may eventually be useful for the Mathathon application.

## Current status

Everything here should be considered preliminary and subject to revision.
